# 5. Major raises (Gavin)

**Law:** SYSTEM.md §6  
**Status:** Stub

Stop in **2M** or bid **game**. Natural game tries. 1M is unlimited, so 2M is **not** a closeout.

**How high opposite 1M (starting points).** Dummy points with a fit. Opener is often 12–14 but may be 19 — he will try if he has extras. **8–10 does not bid game.**

| | Strength | Bid |
|--|----------|-----|
| **Quit** | **0–7** | Pass 1M, or 1NT then 2M if they bid. |
| **Constructive** | **8–10** dummy, 3 trumps | **2M**. Raise with a raise. Not 1♠. Not 4M. |
| **Mixed** | **8–10**, 4 trumps | **3M** |
| **Invite** | **11–12** | <span style="color:#C62828;font-weight:700">3♦</span> with 4 trumps; 1NT then 3M with 3. |
| **Force / game** | **13+** | 2/1 (**2♦/2♥ = 5**; **2♣** catch-all, alert), Jacoby (4+), splinter. Bypass 4♠ over 1♥. |

| Call | Meaning | Table |
|------|---------|--------|
| 2M | Semi-constructive ~8–10 dummy, usually 3 | Card |
| 3M | Mixed ~8–10, **4** trumps | Card (unusual — be ready to explain) |
| <span style="color:#C62828;font-weight:700">3♦</span> | 4-card limit ~11–12 | **Alert** |
| <span style="color:#C62828;font-weight:700">2NT</span> | Jacoby, GF, 4+ | **Alert** |
| <span style="color:#C62828;font-weight:700">1♠ – 3♥</span> | Invite, good 6+ hearts, no spade fit | **Alert** |
| <span style="color:#C62828;font-weight:700">Splinter</span> | GF, shortage | **Alert** |
| <span style="color:#C62828;font-weight:700">2♣</span> by a passed hand | Reverse Drury | **Alert** |

In competition, the mixed jump raise is **off** — jump raise is preemptive.

## <span style="color:#C62828">1♥ / 1♠ – 3♦ — 4-card limit</span>

## Example

**Dealer South · neither vul**

| | ♠ | ♥ | ♦ | ♣ |
|--|--|--|--|--|
| **S** | AKxxx | Qx | Kxx | xxx |
| **N** | Qxxx | Axx | Axxx | xx |

| West | North | East | South |
|------|-------|------|-------|
| | | | 1♠ |
| Pass | <span style="color:#C62828;font-weight:700">3♦</span> | Pass | 4♠ |
| Pass | Pass | Pass | |

**Why:** Four trumps, limit values. South accepts. 2♠ would have been the 8–10 three-card raise; 3♠ would have been mixed (four trumps, less than a limit).

**Tell the opponents:** Alert 3♦ — “four-card limit raise.”
