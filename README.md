# Jay–Pat system book

Explanations and examples for the card in `/mnt/d/Bridge/SYSTEM.md`.

**This is not law.** If a chapter and SYSTEM.md disagree, SYSTEM.md wins.

Written the way Gavin’s Master Series lessons work: one topic, why the call exists, a few deals, what to tell the opponents. No video. No PowerPoint. Source is markdown so Jay and this project can keep editing it.

**Colors** (full rules in [`STYLE.md`](./STYLE.md)):

- <span style="color:#1565C0;font-weight:700">Blue</span> = **Announce**
- <span style="color:#C62828;font-weight:700">Red</span> = **Alert**
- Default = natural / nothing to say

**Pat:** open [Updates](Updates.md). If the top date is new, read the files it names. The card itself is [Overview](Overview.md).

Files are named by subject (`Notrump`, `Majors`, `Minors`, …), not `02-`. If a chapter grows: `Majors-Raises`, `Majors-TwoOverOne`.

Open in Typora or Obsidian if you want the colors. Print/PDF later if Pat wants paper.
