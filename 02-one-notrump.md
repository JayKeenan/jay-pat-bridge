# 2. <span style="color:#1565C0">1NT opening — announce 11 to 14</span>

**Law:** SYSTEM.md §2 (1NT) and §3  
**Status:** Version 00 · 26_08_27  
**Tell the opponents:** **Announce** the opening — “Good eleven to fourteen.”

<span style="color:#1565C0;font-weight:700">1NT</span> is balanced or semi-balanced (4333, 4432, 5332, some 5422). It **may include a five-card major**. A **good 15** always starts with a **suit**.

---

## Good is not the number

**Controls:** A=2, K=1. Queens and jacks are not controls. Rule of 19/20/22 is off.

**Good** means a five-card suit, or concentrated honors with tens and nines. A hand with **only 3 controls, scattered values, and no intermediates can be passed** — even if it has 12 HCP.

### Example — good 11 (3 controls, not junk)

`♠ Q87  ♥ AJT8  ♦ KJ95  ♣ 75` — 11 HCP, 3=4=4=2. Controls: A+K = **3**.

Tens in both red suits, honors working. This is a **1NT** opener.

**Tell the opponents:** Announce “Good eleven to fourteen.”

### Example — 12 that passes (3 controls, junk)

`♠ Q65  ♥ AJ43  ♦ Q832  ♣ K5` — 12 HCP, **same shape**. Controls: A+K = **3**, scattered, no tens.

**Pass.** Partner is not missing a 12-count. He is missing quacks.

### Example — 14 too good for 1NT

`♠ A86  ♥ KQT98  ♦ AJ9  ♣ 63` — 14 HCP, 3=5=3=2.

Five-card heart suit, concentrated. **Too good for 1NT.** Open **1♥**. The 15-to-a-bad-18 notrump type starts with a suit; this 14 is already in that spirit.

---

## Will I have a rebid?

The shape rule is a servant of the rebid. **A reverse shows 18+.** If opening a suit would force a reverse on a 12–14 (or a good 15–17), do not reverse — open 1NT when the hand is balanced/semi-balanced, or rebid cheaply / 1NT after a suit opening.

| You hold | Cheap rebid? | Open |
|----------|--------------|------|
| 5♠ and 4♥ / 4♦ / 4♣ | Yes (2♥ / 2♦ / 2♣) | **1♠** |
| 5♥ and 4♦ / 4♣ | Yes | **1♥** |
| 5♦4♥ or 5♣4♥ (higher suit is hearts) | Reverse if you open 1♦/1♣ then bid hearts | Tend to **1NT** with 12–14 |
| 5♥4♠ 5422, 12–14 | 1♥ then 2♠ is a reverse = 18+ | **1NT** |
| 5♥4♠, **18+** | Reverse is legal | **1♥**, then 2♠ |

Five-card major plus a **lower** four-card suit: open the major. When the **higher** suit is hearts, tend to open 1NT.

This is judgment, not a police rule. If the five-card major is a real suit and you are happy to rebid it, open the major even on some 5422s.

---

## How high opposite 1NT

Opener is **11–14**. Want ~25 for 3NT. These are **starting points** in HCP. Shape and controls may overrule later; they do not make a **10** into an invite.

| | HCP | 4-card major? | Combined vs 11 / vs 14 | You bid |
|--|-----|---------------|--------------------------|---------|
| **Quit** | **0–10** | no | 10+14=**24** | Pass, or transfer and pass (5+M). |
| **Quit** | **0–10** | **yes** | | **Crawling Stayman.** Do not pass 2♦. |
| **Invite** | **11–12** | **no** | 11+14=**25** | <span style="color:#C62828;font-weight:700">2♠</span> **only.** Not Stayman. |
| **Invite** | **11–12** | **yes** | | Stayman, then invite. |
| **Game** | **13+** | no | 13+14=27 | 3NT, or transfer then 3NT (5M). |
| **Game** | **13+** | yes | | Stayman, then game. |

**A 10 does not bid 2♠.** An **11–12 with no four-card major does not bid 2♣.** That invite is the range ask.

---

## Responses

Four-suit transfers, except **2♠ is not a simple club transfer**.

| Response | Meaning | Table |
|----------|---------|--------|
| 2♣ | **Crawling Stayman** — you have a **4-card major** | Card. Crawls **alert**. |
| <span style="color:#1565C0;font-weight:700">2♦</span> | Transfer to hearts | **Announce Hearts** |
| <span style="color:#1565C0;font-weight:700">2♥</span> | Transfer to spades | **Announce Spades** |
| <span style="color:#C62828;font-weight:700">2♠</span> | **Range ask or clubs 6+.** Responder need not have clubs. | **Alert Clubs or Invite** |
| <span style="color:#C62828;font-weight:700">2NT</span> | Transfer to diamonds, **6+** | **Alert Diamonds** |
| 3NT | To play | — |

Major transfers: opener **completes**. No super-accepts in the majors. Garbage: transfer and pass.

Minor transfers show **six or more**. A five-card minor does not transfer.

## <span style="color:#C62828">1NT – 2♠ — range ask or clubs</span>

Opener **must** bid:

| Opener | Meaning |
|--------|---------|
| 2NT | **Minimum** |
| 3♣ | **Maximum** |

Responder v1:

| You meant | Opposite min (2NT) | Opposite max (3♣) |
|-----------|--------------------|-------------------|
| Invite notrump | **Pass** | **3NT** |
| Weak 6+♣, to play | **3♣** | **Pass** |

Responder does **not** necessarily have clubs. The invite-NT hand is why 2♠ is dual-purpose.

Invite or GF with clubs, and other continuations: not written yet.

### Example — range ask, minimum

**Dealer South · neither vul**

South `♠ KJx  ♥ Qxx  ♦ AJxx  ♣ Qxx` — 13, a min 1NT.  
North `♠ Axx  ♥ Kxx  ♦ Qxx  ♣ Jxxx` — 11, invite opposite a max, not opposite a min.

| West | North | East | South |
|------|-------|------|-------|
| | | | <span style="color:#1565C0;font-weight:700">1NT</span> |
| Pass | <span style="color:#C62828;font-weight:700">2♠</span> | Pass | 2NT |
| Pass | Pass | Pass | |

**Why:** South is a minimum. North asked. 2NT is the place.

**Tell the opponents:** Announce 1NT “eleven to fourteen.” Alert 2♠ — “range ask or clubs.” 2NT is a minimum (explain if asked).

### Example — range ask, maximum

Same North. South `♠ AJx  ♥ KQx  ♦ Axxx  ♣ Jxx` — 14, a max 1NT (no five-card suit that upgrades out).

| West | North | East | South |
|------|-------|------|-------|
| | | | <span style="color:#1565C0;font-weight:700">1NT</span> |
| Pass | <span style="color:#C62828;font-weight:700">2♠</span> | Pass | 3♣ |
| Pass | 3NT | Pass | Pass |
| Pass | | | |

**Tell the opponents:** Same alerts. 3♣ = maximum. 3NT is to play.

### Example — weak clubs

North `♠ xx  ♥ xx  ♦ xxx  ♣ QJ10xxx`. South a min.

| West | North | East | South |
|------|-------|------|-------|
| | | | <span style="color:#1565C0;font-weight:700">1NT</span> |
| Pass | <span style="color:#C62828;font-weight:700">2♠</span> | Pass | 2NT |
| Pass | 3♣ | Pass | Pass |
| Pass | | | |

If South had bid **3♣** (max), North **passes** — still playing a club partial, one level higher.

## <span style="color:#C62828">1NT – 2NT — diamonds, 6+</span>

Accept with **3♦** if **fit, maximum, or both**. One is enough. Else **3♣**.

**Fit** = 3+ diamonds, **or** a high-honor doubleton (**Q or better**: Ax / Kx / Qx). Not Jx. Not xx.

| Opener | When |
|--------|------|
| **3♦** | Fit, max, **or both** (fit = 3+ or Hx Q+) |
| **3♣** | Minimum **and** no fit |

A max with xx still bids **3♦**. A min with Qx still bids **3♦**. A min with xx or Jx bids **3♣**.

Weak 6+♦: play 3♦. Pass opener’s 3♦; bid 3♦ over 3♣.

Invite/GF with diamonds: later.

### Example — likes diamonds

South `♠ Kxx  ♥ AJx  ♦ Qxx  ♣ Kxxx` — 13, three diamonds.  
North `♠ xx  ♥ xxx  ♦ KJ10xxx  ♣ xx`.

| West | North | East | South |
|------|-------|------|-------|
| | | | <span style="color:#1565C0;font-weight:700">1NT</span> |
| Pass | <span style="color:#C62828;font-weight:700">2NT</span> | Pass | 3♦ |
| Pass | Pass | Pass | |

**Why:** Three diamonds is a fit. 3♦ does not claim a max.

**Tell the opponents:** Announce 1NT. Alert 2NT — “diamonds.” If they ask about 3♦: “fit or a maximum, or both.”

### Example — does not like diamonds

South `♠ AQxx  ♥ KJx  ♦ xx  ♣ Qxxx` — 13, min, two small diamonds (not Qx). Same North.

| West | North | East | South |
|------|-------|------|-------|
| | | | <span style="color:#1565C0;font-weight:700">1NT</span> |
| Pass | <span style="color:#C62828;font-weight:700">2NT</span> | Pass | 3♣ |
| Pass | 3♦ | Pass | Pass |
| Pass | | | |

**Why:** No fit, not a max → 3♣. North signs off in 3♦.

## Crawling Stayman

**2♣ is for a four-card major** — weak, invitational, or game. It is **not** the 11–12 balanced invite. That hand bids <span style="color:#C62828;font-weight:700">2♠</span>.

Opener: **2♦** = no 4-card major; **2♥** = 4♥; **2♠** = 4♠, not 4♥.

**Quit (weak 4-card major):** if they bid your suit, **pass**. If they bid **2♦**, do not pass — **crawl:**

| After 2♦ | Meaning |
|----------|---------|
| **2♥** | Weak hearts, or both majors (pass or correct) |
| **2♠** | Weak spades only |

If they bid **2♥** and you wanted spades: **2♠** (still weak). **Alert** these crawls.

**Invite with a 4-card major:** 2♣, then 2NT (no fit) or raise. You used Stayman *because* of the major.

### Example — crawl, both majors weak

North `♠ Qxxx  ♥ Jxxx  ♦ xx  ♣ xxx` — 4 HCP. South 1NT, no major.

| West | North | East | South |
|------|-------|------|-------|
| | | | <span style="color:#1565C0;font-weight:700">1NT</span> |
| Pass | 2♣ | Pass | 2♦ |
| Pass | 2♥ | Pass | Pass |
| Pass | | | |

**Why:** Stay safe at the two-level. Passing 2♦ would be garbage Stayman — **off**. 2♥ is pass-or-correct.

**Tell the opponents:** Announce 1NT. Alert 2♥ — “weak, hearts or both majors.”

### Example — invite, no four-card major: range ask, not Stayman

North `♠ Axx  ♥ Kxx  ♦ Qxx  ♣ Jxxx` — 11, no 4-card major.

| West | North | East | South |
|------|-------|------|-------|
| | | | <span style="color:#1565C0;font-weight:700">1NT</span> |
| Pass | <span style="color:#C62828;font-weight:700">2♠</span> | Pass | 2NT |
| Pass | Pass | Pass | |

**Why:** Invite without a major to look for. 2♣ would be a lie about a four-card major and a wrong tool.
