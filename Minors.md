# 1♣ and 1♦

**Law:** SYSTEM.md §2 (1♣ / 1♦), §4, §5, §5a  
**Status:** Version 00 · 26_08_27

**3–3 minors → 1♣. 4–4 minors → 1♦.** Neither is forcing. Partner may pass 1♣. Unlimited. 1♣ is **not** a strong club and **not** alertable.

**The inversion:** 12–14 balanced already opened **1NT**. So after 1♣ or 1♦, a **1NT rebid** and a **raise of responder’s major** are **15–17** (or a shapely hand that could not open 1NT). Do not play opener for a flat 12.

---

## How high

The **first** bid assumes opener might be a min. After **1NT** or a **raise of your major**, you know extras (~15–17).

**First response:**

| | HCP | Bid |
|--|-----|-----|
| **Quit** | 0–5 | Pass (no major). 6–10 no 4M: **1NT**. Light 1M with 6+ and 4 cards is OK. |
| **Invite** | 11–12 | 2NT (no 4M) or inverted 2m. |
| **Force / game** | 13+ | 2/1 in a new minor, or 3NT. |

**After 1m – 1M – 1NT (15–17):**

| | HCP | Bid |
|--|-----|-----|
| **Quit** | **6–7** | **Pass**, or **2M** to play. |
| **Invite** | **8–9** | <span style="color:#C62828;font-weight:700">2♣</span> (2-way NMF). |
| **Force / game** | **10+** | <span style="color:#C62828;font-weight:700">2♦</span> GF, or 3NT. |

A courtesy 1♥ on 6 does **not** become 3NT when they rebid 1NT. 6+15 is a partscore.

**After 1m – 1M – 2NT (18–19):**

| | HCP | Bid |
|--|-----|-----|
| **Quit** | **6** | **Pass**, or **3M** to play. |
| **Game** | **7+** | **3NT** or **4M**. |

No invite. No transfers. A courtesy 6 does not bid 3NT.

**After 1m – 1NT – 2NT (18–19):** no major to run to. **6 pass. 7+ 3NT.**

**After 1m – 1M – 2M (raise):** same idea — opener has four-card support and is **not** a 12-count balanced. Bid as if facing 15–17 or a shapely opening. Same quit-or-game idea if they jump 2NT.

## Opener’s rebid after 1m – 1M

| Rebid | Meaning |
|-------|---------|
| **1NT** | **15–17** balanced-ish. The strong notrump. |
| **2M** (raise) | Four-card support. Treat as **15–17** or shapely (5m4M). Not a flat 12. |
| **1♠** after 1♥ | Four spades (cheap) |
| **2m** | Extra length, not a reverse |
| Reverse | **18+** |
| Jump raise | Extras, 4+ support |
| Jump **2NT** | **18–19** balanced |

### Example — 1NT rebid is 15–17

**Dealer South · neither vul**

South `♠ AJx  ♥ Kxx  ♦ AQxx  ♣ Kxx` — 17.  
North `♠ Kxxx  ♥ Qxxx  ♦ xx  ♣ xxx` — 7.

| West | North | East | South |
|------|-------|------|-------|
| | | | 1♦ |
| Pass | 1♥ | Pass | 1NT |
| Pass | Pass | Pass | |

**Why:** South is too good for opening 1NT. North’s 1♥ was courtesy. Opposite 15–17 a 7 **passes**. 3NT is the leak. Same pass if the auction had been `1♥ – 1♠ – 1NT`.

**Tell the opponents:** If they ask about the 1NT *rebid*: “fifteen to seventeen, balanced.” Do not announce it.

### Example — raise of the major is not a 12-count

South `♠ KQxx  ♥ xx  ♦ AKxx  ♣ QJx` — 16, 4♠4♦. Opens 1♦ (4–4 minors).  
North `♠ Axxx  ♥ xxx  ♦ Qxx  ♣ xxx` — 7.

| West | North | East | South |
|------|-------|------|-------|
| | | | 1♦ |
| Pass | 1♠ | Pass | 2♠ |
| Pass | Pass | Pass | |

**Why:** 12–14 balanced with four spades would have opened **1NT**. This raise is 15–17 (or shape). North still has a 7 — stay in 2♠ unless the dummy is huge.

A 13-count **5♦4♠** also raises 2♠ — shapely min, not 15–17 HCP, but not a flat 12 either. Partner does not bid as if facing a weak-NT 12-count raise.

### Example — jump 2NT, 6 passes

South `♠ AKx  ♥ AQx  ♦ KJxx  ♣ Kxx` — **19**. Opens 1♦, jumps **2NT**.  
North `♠ Qxxx  ♥ xxx  ♦ xx  ♣ xxxx` — **6**, four spades.

| West | North | East | South |
|------|-------|------|-------|
| | | | 1♦ |
| Pass | 1♠ | Pass | 2NT |
| Pass | Pass | Pass | |

**Why:** 19+6 = 25 on a good day, 24 on this one. Quit. 3NT is the leak. With five spades and a 6, North would bid **3♠** to play, not 4♠.

**Tell the opponents:** Nothing. 2NT is 18–19 if they ask.

### Example — jump 2NT, 8 bids game

Same South (19). North `♠ Qxxx  ♥ Kxx  ♦ xx  ♣ xxxx` — **8**.

| West | North | East | South |
|------|-------|------|-------|
| | | | 1♦ |
| Pass | 1♠ | Pass | 2NT |
| Pass | 3NT | Pass | Pass |
| Pass | | | |

**Why:** 8 opposite 18–19 is game. Four spades, no fifth — 3NT, not 4♠. With five or six spades, 4♠.

## <span style="color:#C62828">Two-way NMF</span> (opposite 15–17)

They opened a suit and rebid **1NT**. That is **15–17**, not 12–14. You have already shown a major. Now: stay, invite, or force — and maybe find 5–3 in your major.

**Two-way** means two different bids, not one gadget that does both:

| You mean | Bid |
|----------|-----|
| **Quit** (6–7) | **Pass**, or **2M** to play with five of your major |
| **Invite** (8–9) | <span style="color:#C62828;font-weight:700">2♣</span> — puppet. Opener **must** bid 2♦. Then you show the invite (2M / 2NT / 3m), or **pass 2♦** with weak diamonds. |
| **Force** (10+) | <span style="color:#C62828;font-weight:700">2♦</span> — artificial game force. Or just bid **3NT**. |

Same card after `1♥ – 1♠ – 1NT`. After that auction **2♥** is to play (preference); **2♠** is 2M to play. **2♣ / 2♦** are still the gadget.

Gavin wrote this opposite a *weak* 1NT rebid. We play it opposite the **strong** one. Kantar is off.

### Example — invite, they are 15–17

**Dealer South · neither vul**

South `♠ AJx  ♥ Kxx  ♦ AQxx  ♣ Kxx` — 17, 1♦ then 1NT.  
North `♠ K10xxx  ♥ Qxx  ♦ xx  ♣ Qxx` — **8**, five spades.

| West | North | East | South |
|------|-------|------|-------|
| | | | 1♦ |
| Pass | 1♠ | Pass | 1NT |
| Pass | <span style="color:#C62828;font-weight:700">2♣</span> | Pass | 2♦ |
| Pass | 2♠ | Pass | Pass |
| Pass | | | |

**Why:** 8 opposite 15–17 is invite, not 3NT. 2♣ then 2♠ is the five-card invite. South is a min and sits. If South had extra spades or a max, he would bid on.

**Tell the opponents:** Alert 2♣ — “two-way: 2♣ invite, 2♦ game force.” 2♦ by opener is the forced puppet, not diamonds.
