# <span style="color:#C62828">2♣ — strong, artificial</span>

**Law:** SYSTEM.md §2 (2♣) and §8 (balanced ladder)  
**Status:** Version 00 · 26_08_27  
**Tell the opponents:** **Alert** — “strong, artificial.”

The one purely artificial *opening*. Not Flannery. Not a strong club. **22+** balanced, or a hand that wants **game opposite a lot of nothing**.

| | Open 2♣ |
|--|---------|
| Balanced | **22+** |
| Unbalanced | Game-forcing *playing* strength — about **nine tricks**, or close enough that you still want game if partner is broke |

A **21** balanced is **2NT**. An **18–19** balanced opens a **suit** and jumps to **2NT**. A strong six-card major that is *not* game opposite nothing opens **1♥ / 1♠**.

---

## Where 2♣ sits (do not mix these)

| Balanced | Path |
|----------|------|
| Good **11–14** | Open **1NT** |
| **15–17** | Open a suit, rebid **1NT** (or raise their major) |
| **18–19** | Open a suit, **jump 2NT** |
| **20–21** | **Open 2NT** |
| **22–24** | **2♣**, then **2NT** |
| **25+** | **2♣**, then **3NT** (the “higher” in the ladder) |

The 2NT *opening* is [2-Notrump](2-Notrump.md). This page is only the **2♣** start.

---

## How high (responder)

Opener has forced to **game**, with one exception.

| | You mean | Bid |
|--|----------|-----|
| **Wait** | Almost every hand | <span style="color:#C62828;font-weight:700">2♦</span> |
| **Pass 2NT** | Bust, opposite **22–24** | **Pass** 2NT. The exception. |
| **Raise** | Fit for opener’s suit | Raise. Fast arrival: we have a game, not a slam. |
| **Still waiting** | No fit yet | **2NT** (if it is still cheap) or a new **5+** suit |
| **Game** | You already know the strain | Place it. 3NT / 4M. |
| **Slam** | Later | Do not cue on a bust. Opener will try if the hand is huge. |

Do **not** pass a **suit** rebid. That call is forcing. The only pass is **2♣ – 2♦ – 2NT** with nothing.

---

## <span style="color:#C62828">2♦ — waiting</span>

Always **2♦** (v1). Could be a yarborough. Could be an ace. Could be a five-card major you will name next round.

Do **not** bid **2♥** as a bust. Do **not** name a suit on the first round. Immediate positives and Kokish are later.

**Tell the opponents:** Alert 2♦ — “waiting.”

---

## Opener’s rebid after 2♦

| Rebid | Meaning |
|-------|---------|
| **2NT** | **22–24** balanced (5-card major possible) |
| **3NT** | **25+** balanced |
| Suit (**2♥ / 2♠ / 3♣ / 3♦**) | Natural, **forcing to game** |

After **2NT**, play it like the 2NT opening: **3♣** Stayman, **3♦ / 3♥** transfers (announce), **3NT** to play. Tree in [2-Notrump](2-Notrump.md). You may **pass 2NT** with a bust.

After a **suit:** raise with a raise. **2NT** = still waiting, no fit. A new suit is **5+**.

**2♥** is **hearts**. It is not 22–24 balanced. That mix-up is Kokish, and Kokish is off.

---

## Example — 22–24, partner is broke, pass 2NT

**Dealer South · neither vul**

South `♠ AKJ  ♥ AQx  ♦ KQxx  ♣ AJx` — **22**, balanced.  
North `♠ xxxx  ♥ xxx  ♦ xxx  ♣ xxx` — nothing.

| West | North | East | South |
|------|-------|------|-------|
| | | | <span style="color:#C62828;font-weight:700">2♣</span> |
| Pass | <span style="color:#C62828;font-weight:700">2♦</span> | Pass | 2NT |
| Pass | Pass | Pass | |

**Why:** South is 22–24. North has a bust. **Pass** 2NT is legal. 3NT is the leak.

**Tell the opponents:** Alert 2♣ — “strong, artificial.” Alert 2♦ — “waiting.” 2NT is 22–24 if they ask. Do not announce it.

---

## Example — 20–21 opens 2NT, not 2♣

South `♠ AKx  ♥ AQx  ♦ KJxx  ♣ Axx` — **20**, balanced.

**2NT**, not 2♣. Partner will pass a lot of yarboroughs in peace. If this were 2♣ then 2NT, North would still pass with nothing — but the 20–21 belongs in the 2NT *opening*, so the rest of the card stays honest.

---

## Example — 18–19 opens a suit, jump 2NT

South `♠ AKx  ♥ AQx  ♦ KJxx  ♣ Kxx` — **19**.

**1♦** (or 1♣). If North bids a major, jump **2NT**. This is not a 2♣ opener and not a 2NT opener.

## Example — suit 2♣, wait, raise, stop in game

**Dealer South · neither vul**

| | ♠ | ♥ | ♦ | ♣ |
|--|--|--|--|--|
| **S** | AKQJxx | AKx | AQ | Kx |
| **N** | xxx | xxx | xxx | xxxx |

| West | North | East | South |
|------|-------|------|-------|
| | | | <span style="color:#C62828;font-weight:700">2♣</span> |
| Pass | <span style="color:#C62828;font-weight:700">2♦</span> | Pass | 2♠ |
| Pass | 3♠ | Pass | 4♠ |
| Pass | Pass | Pass | |

**Why:** South is a 2♣ opener (six spades, game opposite nothing). North waits, then raises. No slam try from the bust. Fast arrival.

**Tell the opponents:** Alert 2♣ — “strong, artificial.” Alert 2♦ — “waiting.” 2♠ and 3♠ are natural.

---

## Example — not 22 HCP; still 2♣

South `♠ AKQJxxx  ♥ AKQx  ♦ x  ♣ x` — **17** HCP, about **ten** tricks.

**2♣.** Playing strength, not the point-count. You want to be in game even if North is broke. 1♠ then a later force does not get this job done.

A strong **six-card major with eight tricks** (AKQxxx and an ace, junk else) is still a **one-bid**. You need partner to have something. That is 1♠, not 2♣.

---

## Example — after 2NT, you are not broke

South `♠ AKJ  ♥ AQx  ♦ KQxx  ♣ AJx` — 22 (same as the pass-2NT deal).  
North `♠ Qxx  ♥ Kxxx  ♦ xx  ♣ Qxxx` — 7, four hearts.

| West | North | East | South |
|------|-------|------|-------|
| | | | <span style="color:#C62828;font-weight:700">2♣</span> |
| Pass | <span style="color:#C62828;font-weight:700">2♦</span> | Pass | 2NT |
| Pass | 3♣ | Pass | 3♥ |
| Pass | 4♥ | Pass | Pass |
| Pass | | | |

**Why:** 7 opposite 22 is game. Stayman, then 4♥. North does **not** pass 2NT with a real hand.

**Tell the opponents:** 3♣ is Stayman (on the card). If South had no major, 3♦, North would bid 3NT.
