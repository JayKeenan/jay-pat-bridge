# Weak twos — 2♦ / 2♥ / 2♠

**Law:** SYSTEM.md §2 (weak twos)  
**Status:** Version 00 · 26_08_27

Natural. **2♦ is a weak two again** (not Flannery).

| | Agreement |
|--|-----------|
| HCP | ~**6–10** |
| Length | **Six.** Five only at favorable, 3rd seat, good suit — style, not law. |
| Quality | **Not a crap suit.** Guideline: **3 of the top 5** honors, or equivalent (KQ10xxx, AQJxxx, KJ10xxx). |

A hand worth a **one-bid** opens one. A **10** with six of a major opens **1♥ / 1♠**, not 2M.

No announce. No alert. If they ask, “weak two, six, about six to ten.” Five-card 3rd-seat: explain if asked; do not volunteer a red card.

---

## How high (responder)

Opener is limited. **Stay safe.** A raise is **not** an invite.

| | You mean | Bid |
|--|----------|-----|
| **Quit / preempt** | Fit, no game | Raise to **3**. To play. Opener does not bid again. |
| **Sure game** | Enough opposite 6–10 | **4M** or **3NT**. To play. |
| **Ask** | Invite or better; need a feature | <span style="color:#1565C0;font-weight:700">2NT</span> feature ask |
| **Own suit** | Real suit, forcing one round | New suit |
| **Pass** | No fit, no game | Pass |

Do not raise to 3 as a try for game. That is how a weak two gets to 4 down.

---

## 2NT — feature ask (v1)

Not Ogust. Not Vinny (later).

| Opener | Meaning |
|--------|---------|
| New suit | **A or K** there |
| 3 of own suit | **Min**, no feature |
| 4 of own suit | **Max**, no feature |

Then responder places: pass, 3M, 3NT, 4M.

---

## Example — raise is to play

**Dealer South · neither vul**

South `♠ KQJ10xx  ♥ xx  ♦ Qxx  ♣ xx` — 7, chunky six. **2♠.**  
North `♠ xxx  ♥ Axxx  ♦ Kxx  ♣ xxx` — 8, three spades.

| West | North | East | South |
|------|-------|------|-------|
| | | | 2♠ |
| Pass | 3♠ | Pass | Pass |
| Pass | | | |

**Why:** North is not inviting. 8 opposite 6–10 is a partscore. 3♠ raises the preempt and stays safe. 2NT would be a try North does not own.

**Tell the opponents:** Nothing.

---

## Example — 10 with six opens one, not two

South `♠ AKJ10xx  ♥ Kx  ♦ xxx  ♣ xx` — 10, six spades, a one-bid.

**1♠**, not 2♠. Partner will not treat this as 6–10.

---

## Example — feature ask, min, no feature

South `♠ xx  ♥ KQJ10xx  ♦ xx  ♣ xxx` — 6, min, no side A/K.  
North `♠ AKx  ♥ xx  ♦ AQxx  ♣ Kxxx` — enough to try game if South has a feature or a max.

| West | North | East | South |
|------|-------|------|-------|
| | | | 2♥ |
| Pass | 2NT | Pass | 3♥ |
| Pass | Pass | Pass | |

**Why:** 3♥ = min, no feature. North quits. Opposite a max (4♥) or a side king (3♣/3♦/3♠), North would have bid game.

**Tell the opponents:** 2NT is an ask (feature). Explain if they ask.
